The runtime around the model

Explicit mechanisms.
Inspectable consequences.

The model proposes. The runtime remembers what matters, controls what may happen, and records what actually did.

01 / CONTINUITY

Persistent pursuits

Long-running goals survive sessions. A plain-text compass.md declares what the owner wants the agent to pursue—and where it must stop.

02 / AUTHORITY

Scoped authorization

A permission stays attached to the pursuit that requested it. Ambiguous replies resolve nothing; consequential commands remain separately gated.

03 / EVIDENCE

Execution evidence

Tool calls create a ledger. Recognized completion claims are checked against it and can be intercepted when the claimed work did not occur.

04 / RECOVERY

Checkpointed recovery

Plans revise around failure and resume from useful work instead of silently restarting. Deferred channel messages survive until delivery or visible expiry.

05 / ADAPTATION

Governed learning

Rules and skills carry maturity, reuse checks, demotion, revision history, and repair paths. The learning judge remains in shadow while its signal earns trust.

CURRENT BOUNDARY

Defense in depth,
not a sandbox.

Philont is suitable for dogfooding under a trusted operator—not unattended high-risk production changes.

Why smaller models

Spend intelligence
where it matters.

Model scale is valuable. It should not have to carry the plan, permissions, memory, retries, and proof of execution inside one transient context.
