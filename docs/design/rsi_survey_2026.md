# 2026 RSI / 自进化方法综述 —— philont 可借鉴什么(2026-10-04)

姊妹文档:`memory_interface_evidence.md`(philosophers 实验→philont 代码路径)、`self_evolution_postmortem.md`
(2026-09-20 复盘)。本文只回答一个问题:2026 年公开的自改进 / 自进化 / 记忆方法里,哪些机制有证据、
philont 已有哪些、还能借哪些、哪些明确不借。数字均取自论文摘要,未复现;全部是单一基准上的结果,
没有一篇是在 API 驱动的个人智能体上测的。

## 0. 一句话结论

站得住的方法共享六个性质:**结构化记录而非散文**、**机械验收(测试/预言机/固定题)且保留最优版本**、
**冻结的留出集**、**多次运行报告方差**、**会弃权(不填充、不写)**、**对不安全产物有闸门**。
philont 已有前三个的局部实现(case 库、回放台、评审影子),缺的是:技能修订后的"保优回退"、
自产技能的安全扫描、学习层整体的留出评估与任务顺序打乱。

## 2. 哪些结论互相印证

- **保优而非覆写**:SkillRevise、Skill-α、RSEA、philont 回放台的 keep-better 都是同一件事——改动要在同一道题上
  对比原版才算接受。philont 的技能修订(H3)是唯一没有这一步的学习写入口。
- **留出集**:SEAGym 的"即时增益过不了留出"与本项目 102(先验对照吃掉一半)、105/106(单次差异在噪声内)一致。
- **弃权**:Mem-π(训练出来)、MemArbiter(时间门)、Memento 2(void case)、本项目 103/105(无关取回有害)
  四处独立得到——不相关时什么都不给,比给点什么好。philont 的 no-fill 与 void case 已覆盖,待 A/B。
- **技能不迁移**:Memento-Skills(GAIA)、本项目 107/108(PHYRE、ScienceWorld 家族)、philont 生产日志
  ("多数技能从未触发")三处一致。借鉴意义:别为迁移投入,为**同任务重访**投入。
- **安全**:Practice Makes Unsafe 的数字(21/21)意味着任何自写技能的系统都该默认有扫描,这不是可选项。

## 3. 建议改动(按证据强度与实现成本排序;全部旗标门控、默认关或默认影子)

**A. 技能修订保优回退**(SkillRevise / Skill-α / RSEA)
`reviseRecipe` 已存快照。新增:修订后记录修订时刻的成功率基线;其后 N 次 `recordSkillOutcome`
(N=`MAX_REPAIR_ATTEMPTS` 同源常数 3)若成功率低于修订前,回退到历史中成功率最高的快照,并在
`revision_history` 留 `reason: 'keep_best_revert:…'`。机械验收,不问模型。旗标 `PHILONT_SKILL_KEEP_BEST`(默认 shadow:只记指标不回退)。

**B. 自产技能安全扫描**(Practice Makes Unsafe / SafeEvolve)
在 `SkillStore` 写入与 `skill_recall` 读取两处,对 `actionTemplate`/步骤文本做模式扫描
(破坏性 shell、凭证外传、权限提升、关闭安全闸门的指令)。命中者写入时标 `quarantined`,
召回时跳过并计 `skill.quarantine.*` 指标;审计落 `skill_quarantined`。
旗标 `PHILONT_SKILL_SAFETY_SCAN`(默认 on:扫描只拦自产技能,不改外来技能边界)。

**C. 学习层 A/B 的留出与顺序打乱**(SEAGym / Fragility)
`learning-ab.ts` 增加 `--holdout <family>`(该家族任务只在每个 run 末尾跑一遍,记忆只读)和
`--shuffle`(每个 run 用不同顺序跑演化集,报告按任务对齐)。报告分 ID / 留出两栏。

**D. 后置**(需要先有 A/B 数据):SkillForge 式按失败签名批量诊断→技能级修订提案;
MetaSkill 式慢回路(读 `learning_stats`,改技能模板);预测器从影子转强制。

**不借**:Mem-π / APEx / Memento 学习检索 / Skill-α 的 RL 训练(philont 是 API 模型,无可训参数);
ROAM 的完整关系图(105 在行动记忆上写时合并无增益,ROAM 的领域是长对话问答)。

## 4. 本文的证据边界

所有外部数字来自摘要;本文作者未复现任何一篇。philont 自己的 A/B(`learning-ab.ts`)尚未在真实模型上跑过
(网关 429),所以 §3 的 A/B/C 是"按文献与本项目实验应该有效",不是"已测得有效"。两次运行、留出集、
按模型分层——这三条本身就是本文借来的评估规矩,先于任何结论。
